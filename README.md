# 6-DOF-metal-Robotic-Arm-IP-Control
A wireless 6-DOF robotic arm powered by an ESP32-S3, PCA9685 driver, and 5V 20A SMPS. Hosting its own Wi-Fi web interface, it features real-time slider control for six MG996R servos, live motion recording with smooth loop playback, and RGB LED connection status feedback.
